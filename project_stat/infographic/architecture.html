🤖 ИИ — АГЕНТ

выполняет и собирает
  • Автоматически запускает алгоритмические задачи по расписанию/триггеру
  • Собирает и агрегирует аналитику из сменных логов
  • Формирует отчёт без участия человека (watcher → /api/reanalyze)

💬 ИИ — КОНСУЛЬТАНТ

советует
  • Получает на рассмотрение ключевые данные аналитики
  • Выдаёт рекомендации по узким местам и мерам
  • Отвечает на свободные вопросы оператора в интерфейсе

При накоплении ≥10 партий watcher сам вызывает ИИ-агента. Готовый отчёт и диалог с консультантом — в интерфейсе оператора.
Три компонента демонстрации
1. Генератор отчётовскрипт синтезирует отчёты о работе участков
2. Наблюдатель папкискрипт следит за виртуальной папкой на сервере, куда помещаются отчёты
3. Интерфейс пользователяформирует отчёт и обеспечивает взаимодействие с ИИ-консультантом

Один локальный движок — две функции.
«В данном проекте показан способ взаимодействия ИИ с производством в двух ролях: роли агента, который выполняет алгоритмические задачи и собирает аналитику, и в роли консультанта, которому передаются на рассмотрение ключевые данные аналитики для выдачи рекомендаций.»
Оговорка о модели (для аудитории)
• Техпроцесс упрощён до 4-х участков; нормативные выходы и другие вводные данные — вымышленные.
• Отчёты генерируются с выходами в пределах разных диапазонов около нормативов для приближения к реальному техпроцессу.
• Это демонстрационный стенд: архитектура и способ взаимодействия ИИ с производством, а не промышленный контур.
Компоненты: gen_test_data.py · watcher.py · server.py+ui.html
