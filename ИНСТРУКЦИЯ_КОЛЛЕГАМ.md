# Инструкция для коллег — как поднять стенд project_stat

Тебе нужно: пара минут, ~2 ГБ свободного места на диске и интернет для
скачивания ~1 ГБ (лингвистическая модель). opencode у тебя уже стоит.
Всё остальное сделает агент по скиллу `magic_share.md`.

## Что ты делаешь (по порядку)

**1. Создай папку на своей машине**
   Любое имя, например `C:\stand` (Windows) или `~/stand` (Mac/Linux).

**2. Положи файл скилла `magic_share.md` в эту папку**
   Получить файл можно одним из способов (любой на выбор):
   - **Из общего чата в ТГ** — скачай прикреплённый файл `magic_share.md`.
   - **Из репо** — зайди на https://github.com/multifather/magic_share
     и скачай файл `magic_share.md`.
   Положи скачанный `magic_share.md` в созданную на шаге 1 папку.
   (Это единственный файл, который нужно получить вручную. Остальное
   агент скачает сам из репо.)

**3. Открой opencode**
   Запусти opencode обычным образом.

**4. Начни НОВУЮ сессию и укажи рабочую папку**
   При старте сессии выбери/укажи папку, куда положил `magic_share.md`
   (шаг 1–2). Агент будет работать именно в ней.

**5. Напиши в строке opencode:**
   ```
   выполни skill magic_share.md
   ```
   и нажми Enter.

   *Примечание:* если opencode не находит скилл по имени файла — создай
   внутри рабочей папки путь `.opencode/skills/magic_share/` и скопируй туда
   файл `magic_share.md`, **переименовав его в `SKILL.md`**
   (итоговый файл: `.opencode/skills/magic_share/SKILL.md`). Затем повтори
   шаг 5 с командой `выполни skill magic_share`
   (имя скилла теперь `magic_share`, а не имя файла).

**6. Давай разрешения по мере появления**
   Агент будет спрашивать разрешение перед каждым важным действием
   (клонировать репо, проверить/поставить LM Studio, скачать модель ~1 ГБ,
   поднять локальный сервер, запустить стенд). Просто подтверждай, когда
   согласен.

**7. Готово — запускай и смотри**
   Когда агент спросит, как запустить стенд, выбери
   «Пользователь запускает скрипт» (он даст точную команду) или
   «Агент запускает скрипт» (откроет сам).
   Откроются 4 окна (2×2): проводник с данными, watcher, браузер со
   статистикой, генератор. Через ~15 секунд увидишь отчёт и заключение
   локальной LLM. Наслаждайся зрелищем.

## Что нужно заранее (если ещё нет)
- **Свободно ~2 ГБ на диске** — под код стенда, данные и модель.
- **Интернет для скачивания ~1 ГБ** — лингвистическая модель
  `Qwen2.5-1.5B-Instruct` (~1 ГБ GGUF) скачается при подготовке стенда
  (агент направит, когда дойдёт до этого шага). Плюс само репо и LM Studio.
- **Python 3.10+** — проверь `python --version`. Если нет, агент скажет,
  как поставить.
- **LM Studio** (бесплатно, https://lmstudio.ai) — агент проверит и, если
  нет, направит на установку. Модель `Qwen2.5-1.5B-Instruct` (~1 ГБ)
  скачает сама по инструкции агента.
- Интернет для первоначального клонирования репо и скачивания модели.

## Если что-то не так
- Браузер не открылся / окна встали не в сетку — закрой окна, запусти
  `run.bat` (Windows) или `bash run.sh` (Mac/Linux) заново вручную.
- Стенд работает, но без ИИ-блока («ИИ недоступен») — LM Studio не
  поднял сервер на :1234 или модель не загружена. Подними вручную.
- Любые вопросы — спрашивай автора скилла.
